# Common lists

A list is a process the team runs on some existing records. A good list has a stage, an owner, an amount where money is involved, a reason for losing or passing, and notes. You can create the list. The user adds its stages and attributes in the Attio UI, so suggest them in the draft, ending the stages with the outcomes.

If you're not sure a list applies, ask, and recommend leaving it out. A list is easy to add later.

| List                | On                                                       | Include when                                                                                                   | Not when                                                           | Suggested stages and attributes                                                                                                                         |
| ------------------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
